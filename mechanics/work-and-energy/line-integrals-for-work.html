Line Integrals for Work

< Return

Summary

You need a force and a displacement for work to be exerted; displacement without a force or force without displacement has no work occuring

Work is only done in the direction of the force / direction of displacement

It is a dot product of force and displacement; thus, it is a scalar

No work can occur if the force and displacement is perpendicular to one another; negative work can occur if force points opposite the displacement

Equations

W=Fdcos(θ)

In this topic, we will extend our knowledge of work to two dimensions. So far, we have only dealt with displacement in one-dimension; horizontally, vertically, or parallel to an incline. Now, we drop that requirement.

Unlike the integral for impulse, which integrates over time, which is one-dimensional, position can be expressed in two dimensions, the x-component and the y-component.

To deal with such, we will return to the dot product definition for work.

W=∫dW
W=∫F→⋅dr→

Here, notice the use of dr; this is just a generic position somewhere. Now, we will use one definition of the dot product, being that the dot product is the sum of the products of the two vectors in their component forms, to get this integral.

W=∫F→⋅dr→
W=∫Fxdx+Fydy
W=∫Fxdx+∫Fydy

In this formulation, we have separated it into the work done by the horizontal component of the force and the vertical component of the force along the horizontal and vertical displacement.

Problem 1a

Show that the work done on an object of mass m by the weight, starting at an original position r→0 displacing it to the point r→, is the following equation.

W=−mgΔy

Solution

We note that the weight only has a vertical component. Thus, writing our the integral for work, we have the following. We let going up as positive, so weight will point negative.

W=∫−w→⋅dr→
W=−∫w→⋅dr→
W=−∫wxdx−∫wydy

Here, the horizontal component of the weight is basically useless, and drops out.

W=−∫wydy
W=−∫mgdy
W=−mg∫dy

Now, we will integrate from the initial to the final position; thankfully, this is just the initial vertical position to the final vertical position.

W=−mg∫y0ydy
W=−mg[y−y0]
W=−mgΔy

For the other definition for the dot product, we have this formulation.

W=∫F→⋅dr→
W=∫Fcos(θ)ds

Here, we use the variable ds. This is because, unlike for the above integral, which deals with the displacement in one component, this integral has to deal with every path that could be taken by the object, all at once.

Recall that distance and displacement are not the same; distance is the length of the path taken, while displacement is just the change in initial to final position.

We can use the above formulation if we know, for every single position along the path of distance, the magnitude of the force and the angle between that and of the infinitesimal distance. This is usually a pipe dream.

Problem 1b

What can be said about the equation for the work done by weight? Does it depend on the path of the object? What factors does it depend on?

Solution

The above confirms what we have seen earlier; the work done by weight only depends on the vertical displacement. This means that, for example, when moving a box upstairs, it doesn't matter how long the stairs are; it only matters how high you go.

Another thing to note is that it is path-independent; in other words, it only depends on the initial and final position of the object. Thus, if you move a box up and then move it down to where it started, the weight does not do any work.

Problem 2

Show that the work done on an object of mass m by the kinetic friction, starting at an original position r→0 displacing it to the point r→, is the following equation. Let the length of the path taken for the object be L.

W=−fkL

Solution

This time, we actually know the angle between the force and the displacement for every single position; friction always points opposite the direction of motion, thus θ is always 180°.

W=∫f→k⋅dr→
W=∫fkcos(180°)ds
W=∫−fkds
W=−fk∫ds

What should the bounds of integration be? Well, we started at the start of the path, let's say 0, then we have travelled a distance L. Thus, we integrate from the start of the path to the entire length of the path.

W=−fk∫0Lds
W=−fkL
